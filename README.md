# rainbow.dev

Bu proje, **rainbow** adlı geliştiricinin kişisel web sitesidir. Backend geliştirme, otomasyon sistemleri ve dijital projeler üzerinde yoğunlaşan bir portföy sayfasıdır.

## 🚀 Proje Hakkında

rainbow.dev, modern web teknolojileri (HTML, CSS, JavaScript) ve Tailwind CSS kullanılarak hazırlanmış şık, karanlık tema ağırlıklı ve tek sayfalık (single-page) bir portföy sitesidir.

## 🛠️ Yetenekler ve Teknolojiler

Geliştiricinin yetkinlik alanları:
- HTML, CSS, JavaScript
- PHP, Python
- Linux, Ubuntu, Arch
- Raspberry Pi
